---
title: "Common Errors"
---

| Code  | Description                                                                                                                |
| ----- | -------------------------------------------------------------------------------------------------------------------------- |
| -1    | MQTT connection error                                                                                                      |
| -2    | HTTP status code error on client request                                                                                   |
| -3    | Client failed to obtain Duix resources                                                                                     |
| -4    | Client MQTT connection failure                                                                                             |
| -5    | WebRTC client failed to create SDP (typically ICE server issue)                                                            |
| -6    | WebRTC client failed to set SDP (typically ICE server issue)                                                               |
| -7    | Client session interaction error (e.g., authentication failure, ASR startup failure)                                       |
| 1005  | Server token cannot be empty                                                                                                |
| 1006  | Token service failure                                                                                                       |
| 1007  | Server endpoint not found                                                                                                   |
| 1009  | Insufficient server access quota for user                                                                                   |
| 2002  | Session not found on server                                                                                                 |
| 40001 | Invalid appId or appSecret                                                                                                  |
| 40002 | Internal server error                                                                                                       |
| 50001 | Invalid or empty appId                                                                                                      |
| 50002 | Resource check failed. Contact an administrator                                                                             |
| 50003 | Resource in use. Please check and retry                                                                                     |
| 50004 | Request to human service timed out                                                                                          |
| 50005 | Error obtaining resource from resource group                                                                                |
| 50006 | Signature failed                                                                                                            |
| 50007 | Insufficient total concurrent resources. Please check and retry                                                             |
| 50009 | Resource timed out or is not configured                                                                                     |
