1. Some browsers (especially mobile) require a user gesture to play media. Trigger `start` from a click handler. Even if muted, some browsers won’t display the digital human without a click.
2. On some iOS WeChat browsers, call `navigator.mediaDevices.getUserMedia` to authorize before playing remote streams.
3. If ASR is enabled, `getUserMedia` permission is required. Browsers typically require HTTPS for local debugging.
4. For WeChat Mini Program integration, use a `web-view` component.
5. Some mobile browsers still block autoplay even after a click. On error `4009`, call `resume` in response to a user action.
6. For opening lines, wake words, and interruption phrases, fetch them via OpenAPI (Get Session Details). The SDK does not provide business logic.
7. Some browsers do not support RTC (e.g., Xiaomi Browser).
8. WebRTC does not support HTTP or raw IP access. Use HTTPS and a domain name.
