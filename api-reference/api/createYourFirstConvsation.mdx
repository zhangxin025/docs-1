### Create an account

To use the API, first create a [Duix](http://www.duix.com) account. Click [Go to create](https://duix.com/login).

![Login Pn](/images/login.png)

### Log in to the Duix workspace

After logging in, click the "My Duix" icon in the upper right corner.

### Create a conversation

Click **Create Conversation** or create one from a template:

> **Template character**
>
> - **LLM & TTS/ASR**: Use the platform default configuration or integrate third‑party APIs.
>
> - **Character name**: The name shown when the avatar joins the call.
>
> - **Conversation context**: Enter role docs, backstory, and other text materials.
>
> - **Avatar**: Set a default virtual avatar for the role.

> **Custom character**
>
> - **LLM & TTS/ASR**: Use the platform default configuration or integrate third‑party APIs.
>
> - **Character prompt**: Define identity traits and behavior guidelines.
>
> - **Conversation context**: Enter role docs, backstory, and other text materials.
>
> - **First message**: The first message spoken.
>
> - **Error message (for LLM & TTS/ASR errors)**: Backup script played when errors occur.
>
> - **Avatar**: Set a default virtual avatar for the role.

![Tele Pn](/images/tele.png)

![Createconversation Pn](/images/createconversation.png)

### Start the conversation

To connect your application directly, copy your `app id`, `app key`, and `conversation id`. Click the copy icon to place the value on your clipboard, then paste where needed.

Do not share your `app key`. Anyone with access to it can use your account.

![Startconverstion Pn](/images/startconverstion.png)

### Start integration

After creating the session, start integrating with the API to test end‑to‑end. See the [API docs](https://docs.duix.com/).
