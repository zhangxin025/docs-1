### Create an Account

In order to use our API, first you need to create a [DUIX.COM](http://DUIX.COM) account, click here[Go to create](https://duix.com/login).

![Login Pn](/images/login.png)

### Login to the Platform

After logging in successfully, click the "Avatar" icon in the upper right corner, and then click`Platform`Go to your workbench.\
![Platform.png](https://github.com/zhouahua/duix.com/blob/main/images/Platform.png?raw=true)

### Create a Conversation

You can choose to click directly`Create a conversation`The page creates your first session, or you can choose one first.`role`, refer to the template to create, you can change your favorite when creating a session.`Avatar `,`Background `, choose what you want to use`LLMS`And`Language`Session language, you can also modify`Conversation context`Click.`Create conversation`You can create your first session and start the conversation immediately.

![Home Pn](/home.png)

![Createconversation Pn](/createconversation.png)

### Start Conversation

If you want to connect directly to your application, you can copy it directly.`app id`And`app key`And`conversation id`, click the "copy" icon to paste after successful copying.

Don't show your`app key`To others. If someone gains access to you`app key`, they can use your account as if they were using your password.
![appid.png](/startconversation.png)

### Start Integration

Finally, after the session is successfully created, you can start to run the docking API to view the effect, you can refer **API Docs **.

![Docs Pn](/images/docs.png)
