# Getting started

Prerequisites and support

All plans, including the free plan, include access to our API (Application Programming Interface). The API lets you use Duix features programmatically from your code.

In this section, you'll learn how to create your first Duix session by calling our API endpoints.

Note: The web app is a frontend to the same APIs. With identical settings, the quality and outputs should match. However, generation is non‑deterministic, so responses may vary.

Billing and usage: You need available conversation minutes in your account to start and use a session through the API. You can purchase a plan first ([pricing](https://www.duix.com/pricing)) or begin with the free quota to try the flow.

Given the breadth of the API surface, this section provides a quick overview with examples to get you productive fast.
