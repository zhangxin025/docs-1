## Overview

The conversation ID uniquely links your API calls to a specific Interactive AI avatar conversation. You’ll use this ID to programmatically interact with your avatar via the Duix API.

## How to Get Your Conversation ID

Follow these simple steps to retrieve your conversation ID from the dashboard:

### Step 1: Locate your avatar card

Navigate to your Interactive AI avatar dashboard and find the avatar card you want to work with.

### Step 2: Copy the conversation ID

![](/images/getConversationID.png)

1. Find the **Copy ID** button in the bottom-right of the avatar card
2. Click **Copy ID** to copy the conversation ID to your clipboard

<Tip>
Clicking Copy ID automatically puts the value on your clipboard so you can paste it into code or API calls.
</Tip>
