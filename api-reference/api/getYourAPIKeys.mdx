## Overview

API keys are your credentials for accessing Duix services. Use them to authenticate requests to our API endpoints and manage Interactive AI avatars programmatically.

<Warning>
Never share your API keys publicly. Treat them like passwords and store them in environment variables or a secure secrets manager.
</Warning>

## Getting Your API Keys

Follow these steps to generate your API keys from the Duix platform:

### Step 1: Access Your Duix Dashboard

1. Log in to the [Duix website](https://www.duix.com)
2. Go to your workspace using either:
   - The navigation bar at the top of the page
   - Click on your profile avatar and select **Settings** from the dropdown menu

### Step 2: Navigate to API Settings

1. In your **My Duix** workspace, go to **Settings**
2. Click the **API Keys** tab to open key management

![](/images/get-apikeys.png)

#### Step 3: Generate new API keys
1. Click **Generate** to create a new key pair
2. Copy the keys and store them securely
