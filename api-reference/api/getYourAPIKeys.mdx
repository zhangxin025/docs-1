## Overview

API keys are your authentication credentials for accessing Duix services. These secure tokens allow you to make authenticated requests to our API endpoints and manage your Interactive AI avatars programmatically.

<Warning>
Keep your API keys secure and never share them publicly. Treat them like passwords and store them safely in your environment variables or secure configuration files.
</Warning>

## Getting Your API Keys

Follow these steps to generate your API keys from the Duix platform:

### Step 1: Access Your Duix Dashboard

1. Log in to the [Duix official website](https://www.duix.com)
2. Navigate to your workspace using either:
   - The navigation bar at the top of the page
   - Click on your profile avatar and select **Settings** from the dropdown menu

### Step 2: Navigate to API Settings

1. Once in your **My Duix** workspace, go to the **Settings** page
2. Click on the **API Keys** tab to access your key management area

![](/images/get-apikeys.png)

#### Step 3: Generate New API Keys:
1. Click the **Generate** button to create a new set of API keys
2. Copy the generated keys and store them securely
