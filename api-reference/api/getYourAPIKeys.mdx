### **API Key Overview**

If you are interested in using our API Endpoints, you need an API Key so that we can verify that incoming requests are from your server. Before getting an API key, ensure that you have an active account on the [**Developer Portal**](https://platform.duix.com/home).

## **Step 1: Click platform**

If you are not the first to use the DUIX API or you want to create more applications, click the "Avatar" icon in the upper right corner of the website, then click`Platform`Go to your workbench and check it out. ![Myaccount2 Pn](/images/myaccount2.png)

## **Step 2: Navigate to the API Keys tab**

Find the [**API Keys**](https://platform.tavus.io/api-keys) tab on the Developer Portal. On this page, you can create, delete, and manage your keys.

![Apikeys Pn](/images/apikeys.png)

## **Step 3: Create a new key**

Press the “Create New Key” button on the top right of the API Key page. Enter a name for your key. 

![Createkeys Pn](/images/createkeys.png)

## **Step 4: Save your key**

Once your key is created, make sure you save it in a safe place. We are not able to recover your API Key if you lose it. You should now be able to see your new key on the Developer Portal\!

![apikeys.png](/keyslist.png)


Note: Do not show your app-key to others. If someone gets access to your app-key, they can use your account just like they have your password.

## **Next Steps**

Now that you have an API key, you are able to send requests to any of our API endpoints. Check out our [**OpenAPI**](https://doc.duix.com/openapi) to see how you can create a replica, generate conversations, and start conversations through our APIs. Happy coding\! 🖥️
